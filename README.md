# Counter-Loom

Stress-test a claim by weaving the strongest version of the opposing view (steelman), then your best rebuttal — for opinion columns, panels, and investment theses.

Pick counter-argument classes (evidence gap, hidden trade-off, unintended consequence, false analogy, etc.), draft the steelman and rebuttal for each, sharpen a through-line reply, then copy a clean Markdown brief. LocalStorage persistence, no backend.
